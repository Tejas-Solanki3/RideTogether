# RideTogether illustration assets

All displayed characters and scenes are original AI-generated illustrations, styled using the user-supplied editorial reference. They represent fictional students, not real RideTogether users.

## Scene artwork

| Asset | Usage |
|---|---|
| `assets/illustrations/welcome_people.png` | Unboxed welcome/Get Started community illustration; also registration. |
| `assets/illustrations/shared_ride.png` | Home story card, posting/review and successful ride publication. |
| `assets/illustrations/find_your_people.png` | Route search, posting details and empty/error states. |
| `assets/illustrations/good_company.png` | Login, connection confirmation, conversation and connection empty states. |

The illustrations use angular faces, layered flat colors and subtle paper texture, with a restrained ochre/terracotta/charcoal/teal palette. Scene backgrounds are transparent. The Get Started artwork is placed directly on the white screen, without a border, rounded card, background fill or photo-label overlay.

## Portraits

`assets/avatars/aarav.jpg`, `ananya.jpg` and `rohan.jpg` are now coordinated **illustrated portraits**, not stock photographs. The canonical demo still uses `aarav.jpg` and keeps the Ishaan Mehta / `demo_ishaan` identity. Asset names are not identity claims.

The previous campus photograph has been deleted. No photographic UI assets remain in the application bundle.

## Other original and licensed assets

- `assets/svg/logo.svg` and the Android launcher vector: original monochrome route-arrow branding.
- Dart `RouteMap`: original grayscale campus illustration, not GPS/navigation data.
- `assets/icons/*.svg`: bundled Lucide outline icons. Upstream license is included at `assets/icons/LICENSE`.
- `assets/fonts/Manrope.ttf`: Manrope variable font from Google Fonts; SIL Open Font License included at `assets/fonts/OFL.txt`.

All assets are local; runtime CDN image/font fetching is not required.
